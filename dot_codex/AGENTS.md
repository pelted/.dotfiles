# Global Agent Instructions (Codex)

My global preferences and hard rules live in `~/.context/agent-instructions.md`.
Read that file and follow it — it is the source of truth for how I want AI
tools to work (code style, testing, secrets, commit/PR conventions, the
no-co-authoring rule, etc.).

Durable, cross-device context and memory live in `~/.context/` — a private git
repo synced across my machines, independent of any vendor account. Start with
`~/.context/dashboard.md` for the table of contents, and record durable facts
there rather than in tool-local memory.
